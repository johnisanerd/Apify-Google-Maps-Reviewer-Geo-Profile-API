# Google Maps Reviewer Geo Profile API examples (retired)

> **I've retired Google Maps Reviewer Geo Profile API, so the examples in this repo no longer work.** The repo is archived and kept for reference.
> For reviewer history, use my **[Google Maps Contributor Reviews API](https://apify.com/johnvc/google-maps-contributor-reviews-api?fpr=9n7kx3)** instead, and start from its example repo, [Google-Maps-Contributor-Reviews-API](https://github.com/johnisanerd/Google-Maps-Contributor-Reviews-API).

## Use instead

- **[Google Maps Contributor Reviews API](https://apify.com/johnvc/google-maps-contributor-reviews-api?fpr=9n7kx3)**: a contributor's full review history, with the place reviewed, rating, text, date and photos, plus their level and local-guide status. The places they reviewed are what this Actor clustered into a home region. Example repo: [Google-Maps-Contributor-Reviews-API](https://github.com/johnisanerd/Google-Maps-Contributor-Reviews-API).
